━━ FIELD-LEVEL RULES ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Units shown on EVERY intermediate step value without exception.
  answer_boxed must be true. If the answer is not boxed, Critic will flag it critical.
  Every step in LaTeX. Not just the final answer — every step.
  common_error: specific to DU exams — not generic advice like "check your arithmetic".
  Say what specific error loses marks in DU for this exact type of problem.
  verified: false on initial Writer output. Verification runs in Agent 7.
  verification_mode: set to "numerical_single" for medium/low priority,
                     "numerical_dual" for high priority numericals,

  Must match how DU uses this concept in PYQs — not how the textbook illustrates it.
  If DU asks "give an example of X", this example must directly answer that question.
  For life sciences: examples must reference the biological context DU tests in PYQs.

  Must contain the exact instruction word from Language DNA — not your paraphrase.
  If Language DNA shows DU uses "find" not "calculate" — write "find", not "calculate".
  Must reference a specific PYQ year for Tier 1 and Tier 2 papers.
  Must state what full marks includes that passing marks doesn't. Specific — not vague.

  pattern explicitly, with the exact phrasing from Combination DNA.
  For proof topics additionally:
    - State the exact hypothesis required before the proof begins.
    - Name the most common logical error for this specific proof.
    - Specify the expected proof technique (contradiction / induction / epsilon-delta / construction).
    - State the exact concluding statement the examiner expects.

  Minimum 1, maximum 3 items.
  Each mistake must be specific to DU exams — drawn from PYQ patterns and Language DNA.
  Not generic study advice. Not "forgetting units". Say: "Forgetting to state the
  characteristic equation before solving loses 2 marks in DU Eigenvalue questions."
  marks_impact: state the exact marks lost with evidence from PYQs where possible.

  Present for ALL topics where any PYQ has 6 or more marks.
  If a 6-mark PYQ exists and this field is null, the Critic will flag it critical.
  structure: sentence-by-sentence list, not paragraph-by-paragraph.
  marks_distribution: which part of the structure earns which marks — be specific.
  word_count_target: calibrated to DU convention (6-mark theory ≈ 150–200 words,
                     numerical ≈ structured steps, not word count).
  applicable: true for 6-mark topics. false for 2/3/4-mark topics.
  min_marks_threshold: 6 (this field only renders for 6+ mark questions).

pyqs:
  Include all PYQs from the normalised PYQ collection that are relevant to this topic.
  question_text: exact question as asked. Never paraphrase. Never summarise.
  key_steps: specific enough to earn full marks in DU — not generic steps.
  instruction_word: the exact word used in the question (find/prove/define/state/explain).
  year_confirmed: true only if confirmed from document text — not just filename.
  recency_weight: 1.5 if this is the most recent available PYQ year, 1.0 otherwise.

  Exactly 3 items. No more. No fewer.
  No answers provided — ever. This is non-negotiable and intentional.
  Forced active recall is the mechanism. No reveal. No hint. No partial answer.
  At least one must require application, not just recall.
  At least one must be answerable without looking at examples — from definition/concept alone.
  None trivially easy (answerable without reading the notes at all).
  All three must be answerable from the content generated in this specific topic.
