━━ CALL 1 — TOPIC DNA + LANGUAGE DNA ━━━━━━━━━━━━━━━━━━━━━━━━━━
Output two JSON arrays separated by the exact delimiter: ---DNA_SPLIT---
No prose before, after, or between. Only the two arrays and the delimiter.

ARRAY 1 — TOPIC DNA
One object per topic that appears in ANY normalised PYQ.
Topics not in any PYQ are NOT included here — they are handled by the Mapper as never_asked.

[{
  "topic_name":         "string — exact name from normalised PYQ topic_hint",
  "appearances":        [{ "year": int, "marks": int, "question_type": "string", "unit": int }],
  "total_appearances":  integer,
  "marks_trend":        "increasing | stable | decreasing | single_appearance",
  "priority":           "high | medium | low | never_asked",
  "never_asked":        boolean,
  "recency_weight":     number
}]

Priority rules — apply exactly:
  high:        2+ appearances across any years, OR first appearance in the most recent PYQ year at 6+ marks.
  medium:      Exactly 1 appearance, 3-6 marks.
  low:         Exactly 1 appearance, 2 marks or less.
  never_asked: On syllabus, zero PYQ appearances. (Only set if explicitly inferrable from context — usually skip.)

Recency weight rules:
  1.5 — topic appears in the single most recent PYQ year available.
  1.0 — all other topics.

marks_trend rules:
  increasing        — marks awarded to this topic have grown across years.
  decreasing        — marks awarded have shrunk across years.
  stable            — same marks range across years.
  single_appearance — only one year's data exists for this topic.

question_type: extract verbatim from the instruction word used in the PYQ.
  Examples: "find", "prove", "define", "state", "explain", "derive", "calculate", "describe".
  Do not standardise. If DU wrote "evaluate" — use "evaluate", not "calculate".

ARRAY 2 — LANGUAGE DNA
One object per topic that appears in ANY normalised PYQ.

[{
  "topic_name":          "string — must match topic_name in Array 1 exactly",
  "instruction_words":   {
    "find": int, "prove": int, "define": int, "state": int,
    "explain": int, "derive": int, "calculate": int, "describe": int
  },
  "examiner_vocabulary": ["exact repeated phrases from question texts — only phrases that appear 2+ times verbatim"],
  "typical_phrasing":    "the single most common full question phrasing for this topic, verbatim"
}]

instruction_words: count every occurrence across all PYQ years. If DU used "find" for this topic 3 times total across 3 papers — find: 3.
examiner_vocabulary: phrases that appear MORE THAN ONCE verbatim across PYQ years. If a phrase only appeared once, do not include it.
typical_phrasing: pick the single question phrasing that appeared most often. If tied, use the most recent year's phrasing.

━━ CALL 2 — COMBINATION DNA ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Analyse PYQ papers for question combination patterns.
A combination is when two topics appear in the SAME question (same question number, same PYQ year).

[{
  "topic_name":            "string — must match topic_name in Topic DNA exactly",
  "always_asked_with":     ["topics always combined with this one in the same question"],
  "combination_pattern":   "exact phrasing pattern when combined — verbatim from PYQ",
  "standalone_frequency":  number between 0.0 and 1.0,
  "diagram_required":      boolean,
  "numerical_always":      boolean
}]

always_asked_with: list only topics that appear in the SAME question at least 2+ times. If always standalone — empty list [].
standalone_frequency: proportion of appearances where this topic was NOT combined with another.
  If always standalone: 1.0. If always combined: 0.0.
diagram_required: true only if 2+ PYQs explicitly ask for a diagram/figure/labelled drawing for this topic.
numerical_always: true only if every PYQ for this topic requires calculation/derivation — no theory-only questions.
combination_pattern: the exact question phrasing that combines two topics.
  If no pattern: "No consistent combination pattern detected."

━━ FAILURE MODES ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Only one PYQ year available:
  All marks_trend = "single_appearance".
  All recency_weight = 1.5.
  Priority rules still apply (high if 6+ marks, medium if 3-6, low if 2 or less).
  Combination DNA still runs — can still detect combinations within a single paper.

Topic appears in PYQ but topic_hint is ambiguous:
  Use the question_text to infer the closest syllabus topic name.
  Do not collapse multiple syllabus topics into one.

Topic appears with wildly varying marks across years:
  marks_trend = "stable" if the range is within 2 marks.
  marks_trend = "increasing" or "decreasing" only if the direction is consistent.
